# 内的土壌ノート（プロトタイプ）

COACHING-L「内的土壌理論・内的土壌成長モデル」の **STEP1〜3（自己認識 → 自己知識 → 自己理解・自己受容）** を、既存クライアントがセッションの前にひとりで進めるためのWebアプリです。

- AIは使っていません。候補の出し方などは、すべて `src/content/` のルールで決まります。
- 記録は**利用者の端末（ブラウザ）の中だけ**に保存されます。サーバーへの送信はありません。
- スマホのブラウザで使う前提の画面です（ホーム画面に追加して、アプリのように使うこともできます）。

## できること

| 画面 | 内容 |
|---|---|
| STEP1 刺激と反応 | 出来事（事実）と受け取り方（解釈）を分けて書く。感情・強さ・身体の反応・頭の中の言葉・行動・本当はどうしたかったか |
| STEP2 自己知識 | 当てはまる「サイン」とSTEP1の言葉から、関係していそうな領域を**仮説として**最大3つ、理由つきで表示。選べるのは最大2領域。領域ごとにガイドの問いに答え、気づきを一言で書く |
| STEP3 理解と受容 | 「何を守ろうとしていたか」。回答から**つながりの一文**を下書き（書き直し可）。受容は「今の私には、〔　〕という側面がある。」または「まだ受け入れられない」 |
| まとめ | 内省カード、次に気づきたいサイン、コーチと話したいこと、終えてみての気持ち（「しんどくなった」には相談窓口を表示）。**セッション準備シート**（ガイド第9章の形式）のコピー・共有・印刷 |
| さっと記録 | 出来事と反応だけを1〜2分で記録し、あとで続きを深める |
| これまでの記録 | 記録の一覧・続きから再開・削除 |

STEP4〜6（意思決定・行動・内省・統合）は、コーチとのセッションで扱う前提で、アプリには入れていません。

## 文言・問いを変えるには

アプリに出てくる文章は、すべて `src/content/` にまとまっています。プログラムを触らずに書き換えられます。

| ファイル | 中身 |
|---|---|
| `src/content/app.ts` | アプリ名、各画面の説明文、STEP3の問い、ご利用にあたっての注意書き |
| `src/content/domains.ts` | 10領域の説明と問い（ガイド第4章より） |
| `src/content/signs.ts` | STEP2の「サイン」と、領域の候補を出すルール |
| `src/content/reactions.ts` | 感情・身体の反応の選択肢 |
| `src/content/support.ts` | 相談窓口 |

## 公開前に確認したいこと

- [ ] 相談窓口の番号・受付時間（2026年10月に厚生労働省のページで確認済み。公開時に再確認してください）
- [ ] 「ご利用にあたって」の文言（`src/content/app.ts` の `DISCLAIMER`）
- [ ] アプリ名（仮で「内的土壌ノート」にしています）
- [ ] 10領域の問いの選び方（行動の設計に踏み込む問いは、意図的に外しています）

## 開発者向け

```bash
npm install
npm run dev        # 開発用サーバー（http://localhost:5173）
npm test           # テスト
npm run build      # 公開用ファイルを dist/ に出力
```

`dist/` フォルダの中身を、静的サイトを置けるサービス（Netlify、Vercel、Cloudflare Pages、GitHub Pages など）に置けば公開できます。どのURL配下に置いても動くようにしてあります。

構成：React + TypeScript + Vite。画面は `src/screens/`、処理は `src/lib/`（候補の算出 `suggest.ts`、文章の組み立て `compose.ts`、保存 `storage.ts`）。
